# the-clive.com

Site du groupe The Clive (Biel/Bienne).

- `site/` : les fichiers publiés tels quels (HTML statique, polices Jost auto-hébergées).
- `.github/workflows/deploy.yml` : à chaque modification de `site/` sur `main`, le site est publié sur GitHub Pages.
- Domaine : `www.the-clive.com` (fichier `site/CNAME`).
